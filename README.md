# Controle de Gastos — SLZ Administradora de Condomínios

Sistema de controle de gastos mensais do escritório da SLZ, a partir de Novembro de 2026.

- Contas fixas (Energia, Internet, Sistema Superlógica) com vencimento, valor e lembretes
- Despesas variáveis: almoço, papel, toner, tinta, Uber e outros
- Balancete mensal comparando com o mês anterior (impressão/PDF e exportação CSV)
- Backup e restauração dos dados em JSON

## Como usar

Abra o `index.html` no navegador. Os dados ficam salvos no navegador do computador — use **Configurações → Baixar backup** com frequência.
